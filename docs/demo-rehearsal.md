# Facilities Voice Agent demo rehearsal

## Start your shift

From the repository root, run `./start.cmd`. If the app was already open when you updated it, run `./restart.cmd`. Select **Start call** in the right sidebar and wait for **Listening**. The avatar appears when Beyond Presence joins. If video is unavailable, the call uses voice and still shows the transcript. Select **End call** when finished.

## 1. Handle your first maintenance request

| Try this | Look for this |
| --- | --- |
| “What do I need before I open a maintenance ticket?” | A spoken answer and an **Intake checklist** citation in the transcript. Open it to see the exact passage highlighted on page 2. |
| “Walk me through a maintenance request from intake to handoff.” | The canvas opens on the left half of the screen. The avatar and conversation stay visible on the right. Seven approved steps appear with the narration. The citation remains in the conversation. |
| Zoom in, drag to inspect a branch, then select **Fit view** and **Save as PNG**. | You can inspect the diagram after narration. The exported image includes the complete workflow. |

For a second run, speak while a step is being narrated to interrupt it. Ask for the same walkthrough to start it again. You can also say “Close the workflow canvas.”

## 2. Take over the afternoon shift

| Try this | Look for this |
| --- | --- |
| “A ticket has no owner. When do I follow up, and who do I tell?” | A cited answer from the **Shift Handoff Guide**. Open the Word citation to see the reminder highlighted under **Unassigned tickets**. |
| “Which open ticket is due first, and who owns it?” | The sample queue identifies **FM-104** and the **Desk Lead**. |
| “Which ticket is due first, and what budget do we have for repairs?” | The answer cites the deadline and explains that the supplied sources lack budget information. |

With the canvas closed, try **Full screen** on a citation, then press **Esc** to return. Scroll the conversation to revisit an earlier source.

## 3. Brief the team on workload and responsibilities

| Try this | Look for this |
| --- | --- |
| “Draw a bar chart with 12 requests in January, 18 in February, and 15 in March.” | The chart uses your three values and shows beside the avatar. Save it as a PNG when complete. |
| “Draw a swimlane for this example. The Service Desk logs a request, Maintenance reviews it, and the Desk Lead confirms the handoff.” | An illustrative process diagram separates the three roles while the agent describes each step. |
| “Draw a timeline with intake on Monday, assignment on Tuesday, and follow-up on Friday.” | The milestones appear in order. You can also ask for a flowchart with a decision or a hierarchy with reporting lines. |

To try camera movement, ask “Draw a diagram of a service desk connected to a maintenance team. Zoom in on Maintenance, move it to the right, then fit the whole diagram.” Check that the connector follows the moved box.

## 4. Find a guide on a busy desktop

Leave the canvas open from the previous case. Open a few normal windows so you can see how the app hands over the desktop.

| Try this | Look for this |
| --- | --- |
| “Open the Facilities onboarding folder.” | The sidebar and canvas hide before the agent uses the desktop. File Explorer opens the sample folder and keeps focus. The sidebar shows the request and reply. Select **Show canvas** to bring the previous diagram back. |
| “Open example.com in a new Chrome tab.” | The agent opens a new tab and preserves existing tabs. The blue screen border indicates active desktop control. |
| “Open Notepad and type ‘Facilities handoff rehearsal’ into a new document. Leave it open.” | The agent switches to a native app, enters the text, and leaves it available for review. |
| “Open the Facilities onboarding folder and tell me what I need before I open a maintenance ticket.” | Desktop navigation completes first. Then the sidebar shows the cited answer. |

Press **Ctrl+Alt+Shift+Backspace** to take over during a desktop action. Use the sidebar’s collapse and expand buttons to try keeping the call in the edge tab between questions.
